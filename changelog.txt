**本模块 26.11.19_1**　发布于 04:51 UTC+8

- 修复面板里安装、升级插件失败（报「No such file or directory」）：插件是桌面 Linux 的程序，启动前要找系统的动态链接器，Android 没有这个路径，而面板装完是立刻拉起，于是失败并回滚。现在改为在拉起的那一刻用模块自带的链接器，插件文件本身不再被修改——「下载并安装」和自动升级都能一次成功，装完即用，不用重启，也不会再显示「未签名」。
- 补齐三个旧的库名（libpthread.so.0、libdl.so.2、librt.so.1）：Magpie / OpenCode 这类脚本插件依赖的 Bun 运行时仍按这几个名字找库，而 glibc 2.34 之后它们已并入 libc，发行版只留空壳。模块现在一并提供，装这类插件不再报「cannot open shared object file」。
- 「打开」页原来是一个「打开面板」，现在拆成两个：左边「打开桌面面板」、右边「打开手机面板」（同一个服务下的 /m 页面，手机上更好点），两种颜色区分。

**上游 3.5.0-beta.2 的改动**

**核心更新**
- 新增：软件与插件改由官网检查更新和下载，正式版与 beta 版仍可分别关注；安装包全部上传并校验通过后才开放更新。
- 更新：提供商插件全面转向独立 WASM 包，旧原生插件停止运行；保留已有账号和配置，可按账号需要安装对应插件。
- 新增：Claude、ChatGPT 与 Codex 订阅接入。Claude 使用本机已登录的官方 Claude Code；ChatGPT 与 Codex 提供各自的授权入口，不与普通 API Key 混用。相关链路尚未完成真实账号验收。
- 新增：系统提示词规则，可按提供商、客户端和模型匹配，选择替换、追加或原样透传，并预览命中结果。
- 新增：统一错误处理设置，分别配置限流、额度耗尽、登录失效、连接异常等情况的重发、换号、冷却和失败保护。
- 新增：运行容量管理，可自动或手动设置对话、登录、后台任务及图片任务的并发与排队上限，资源紧张时限制新增任务。
- 新增：网页工具调用模拟，为明确声明支持的智谱清言、DeepSeek 网页与 Tabbit 模型转换工具声明、历史和结果；可关闭，不代表网页原生工具能力，尚未实测。
- 新增：插件批量安装、更新、启用、停用和卸载，展示逐项进度与结果；单项失败不影响其余插件，保留账号数据。
- 新增：受支持的 Windows 本机客户端可切换到指定账号后启动，修改凭证前展示范围并备份，支持恢复原凭证；当前接通 Antigravity。
- 优化：插件登录、短信、人机验证、本机凭据读取和服务器访问权限统一展示，敏感能力需独立确认，插件变化后重新核对授权。

**其他更新**
- 优化：账号列表采用按需分页与实时状态更新，减少重复读取和整页刷新，完善分组统计、余额汇总与排序。
- 优化：余额查询统一排队，区分等待超时、查询超时、缺少授权和凭据失效，提供对应恢复入口。
- 优化：凭据续期核对原值并持久保存结果，减少并发覆盖；结果不确定时不重复消耗一次性刷新材料。
- 优化：搜索服务支持多密钥排序与自动切换，分别展示搜索和网页抓取的额度、限流及恢复状态。
- 优化：流式响应、工具续接和取消处理保留真实结束状态，已经发送或结果不明的请求不自动重复提交。
- 新增：Linux 桌面端硬件加速开关与兼容模式重启入口，用于处理白屏、画面不更新或点击无响应。
- 优化：签到中心集中管理插件附带任务，展示执行计划、最近结果和未确认状态，减少重复执行。
- 更新：同步手机端账号、插件、路由、提示词与更新设置，补齐六语文案和前端资源。
- 更新：同步安装说明、官网入口与赞助商展示，移除已不适用的自定义更新源和 GitHub 加速源说明。
- 版本：3.5.0-beta.1 → 3.5.0-beta.2
