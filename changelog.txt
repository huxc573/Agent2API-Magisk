**上游 3.6.1-beta.1 的改动**

**核心更新**
- 新增：网关 API Key 支持用量限额与独立台账，可按 Token 用量或请求次数设置每日、每周、每月及累计上限，桌面端与手机端同步支持查看与管理。
- 新增：本地隐私脱敏支持 Anthropic 与 Responses 原生协议流式还原，重构离线敏感信息检测与流式帧重组保护，并补齐配置保存冲突校验。
- 新增：Windows 桌面端支持客户端数字签名校验与「仅切换凭证」模式，为 Antigravity CLI (`agy`) 切换提供宿主支持。
- 优化：升级余额或积分不足的冷却策略，按账号记录余额水位并递增等待，后续余额回升或变为无上限时自动恢复；同时增强 429 内嵌 402 等余额不足信号的识别。
- 优化：重构请求详情与协议展示，清晰区分原协议与跨协议转换，新增大文本分页预览与防卡顿保护，并为已入库的 Antigravity 本机直连历史记录补全思考等级识别。
- 修复：修复主程序在补全模型元数据时漏认 11 家插件思考档位字段的问题；明确不支持思考的模型不再由社区库补齐档位，模型页与测试弹窗也不再回落到通用档位表。

**其他更新**
- 优化：系统提示词规则支持按映射后的上游模型名匹配；改进客户端配置弹窗交互、插件商店下载次数展示、网页工具调用代码块容错解析以及安卓端应用内更新安装与版本校验。
- 更新：同步六语种多语言词典、桌面端与手机端前端构建产物，补充本地开发隔离说明。
- 版本：3.6.0 → 3.6.1-beta.1
