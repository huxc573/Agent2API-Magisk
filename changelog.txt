**本模块 26.11.10_3**　发布于 18:12 UTC+8

- 修复面板里安装、升级插件失败（报「No such file or directory」）：插件是桌面 Linux 的程序，启动前要找系统的动态链接器，Android 没有这个路径，而面板装完是立刻拉起，于是失败并回滚。现在改为在拉起的那一刻用模块自带的链接器，插件文件本身不再被修改——「下载并安装」和自动升级都能一次成功，装完即用，不用重启，也不会再显示「未签名」。
- 补齐三个旧的库名（libpthread.so.0、libdl.so.2、librt.so.1）：Magpie / OpenCode 这类脚本插件依赖的 Bun 运行时仍按这几个名字找库，而 glibc 2.34 之后它们已并入 libc，发行版只留空壳。模块现在一并提供，装这类插件不再报「cannot open shared object file」。
- 「打开」页原来是一个「打开面板」，现在拆成两个：左边「打开桌面面板」、右边「打开手机面板」（同一个服务下的 /m 页面，手机上更好点），两种颜色区分。

**上游 3.5.0-beta.1 的改动**

**核心更新**
- 新增：独立 WASM 插件支持，在隔离环境中运行，不向插件直接开放本机文件、进程和环境变量。
- 新增：Magpie、OpenCode 插件目录，支持从 npm、GitHub 固定提交或本地路径安装与管理插件。
- 新增：QuWork 账号接入，支持导入本机登录态或粘贴凭证，区分模型调用与账号管理凭证。
- 新增：客户端接入多配置管理，支持新增、切换和停用，写入前预览并自动备份；补充 DSH 配置目标。
- 新增：图片兼容设置，支持辅助识图、切换视觉模型及备选模型；工具服务支持生成、编辑图片和查询任务结果。
- 新增：临期凭证与模型目录自动维护，账号列表支持批量刷新凭证。
- 新增：面板名称与 Logo 自定义，以及可分别设置的桌面端、网页端登录人机验证。
- 优化：统计报表、请求回放和账号额度展示，补充用量趋势、缓存命中率、耗时分段及额度来源。
- 优化：原生协议请求与响应直通，改善工具调用兼容性，完善对话模型查询、能力展示及 Codex 回答阶段标记。

**其他更新**
- 优化：网络访问设置明确区分 API 与管理地址，补充代理链和系统代理；代理异常时不再静默改走直连。
- 优化：签到中心活动与体验套餐展示，支持领取状态筛选和批量查询，结果待确认时避免重复提交。
- 优化：降低长时间运行时的内存与数据库开销，减少请求、日志和调试信息的重复保存。
- 优化：云同步按实际变化上传，支持最小同步间隔和失败重试，保留本机改动。
- 优化：插件更新等待在途任务结束，失败时恢复旧插件；GitHub 下载线路显示限流等待和可重试状态。
- 新增：页面自动刷新间隔、阅读模式与未挂载映射批量删除。
- 修复：修改客户端 TOML 配置时丢失原有注释与格式的问题。
- 修复：签到页面账号列表上下间距被清零导致的显示异常。
- 更新：同步手机端功能、六语文案和安装说明，统一 Docker 与桌面端构建兼容配置。
- 移除：本轮 beta 暂不提供电脑端 Codex 对话及官方终端共享，保留普通模型对话和其他 Codex 接入功能。
- 版本：3.4.2 → 3.5.0-beta.1
