**本模块 26.11.23_1**　发布于 23:14 UTC+8

**上游 3.5.0 的改动**

**核心更新**
- 新增：提供商插件全面转向独立 WASM 沙箱架构，按需独立安装与更新，不直接暴露本机文件、进程与环境变量；支持批量安装、更新、启停和卸载，旧原生插件停止支持但完整保留已有账号与配置。
- 新增：Magpie / OpenCode 社区插件目录，支持通过官网 CDN 聚合清单浏览，并可从官方分发源、npm、GitHub 固定提交或本地路径安装与管理插件。
- 新增：正式发布 Android（`.apk`）与 iOS（`.ipa`，未签名需自行重签）手机端安装包并同步至官网与 CDN，全面升级手机端卡片式管理界面，支持检查更新、应用内下载校验及系统浏览器外链跳转。
- 新增：模型计价与费用估算体系，支持切换显示货币、刷新汇率、自定义单价或参考基准价，以及按提供商倍率、分时窗口和账号维度估算费用并在请求记录与报表中展示。
- 新增：软件更新与插件目录统一改由官网 CDN 静态源优先分发并保留接口回退；服务端面板更新后自动跳过旧页缓存并确认新版本就绪后再刷新，兼容旧版手机端更新校验。
- 新增：系统提示词规则、统一错误处理与插件默认例外规则、运行容量并发与排队管理、图片兼容与工具生图服务，以及网页模型工具调用模拟能力。
- 新增：Agent 客户端多配置管理（写入前预览并自动备份，新增 DSH 配置目标）、面板品牌名称与 Logo 自定义、Cloudflare Turnstile 人机验证、Google / GitHub 第三方登录绑定、Webhook / Telegram / Bark 通知渠道与 S3 兼容云同步。
- 新增：定时任务与自动维护体系，纳入软件更新、插件目录、兼容插件、临期凭证（动态提前量）与模型目录维护，并支持受支持的 Windows 客户端按指定账号热切换启动。
- 优化：原生协议请求与响应直通、插件大正文分片传输与更高内存上限；重构账号按需分页与多窗口配额合并展示，优化请求日志按需查询与统计报表，显著降低长稳运行的内存与数据库开销。

**其他更新**
- 优化：重构「设置 → 账户」与网络访问页面，明确区分 API 与管理地址，新增代理链与系统代理支持且异常时不再静默直连；简化单提供商插件启停开关并标识跨插件接管状态。
- 优化：完善桌面与手机端多窗口配额的短窗优先排序及周限耗尽归零判定；细化代理、网络、限流、签到活动与插件目录异常的可读错误提示。
- 修复：修复 GitHub 社区插件更新时误用旧清单缓存导致重装旧版、更新结束后短时残留「可更新」标记以及提交编号误拼 `v` 前缀的问题。
- 修复：增强本地数据库锁防重入保护、上游账号冷却与挂起状态落盘容错，以及弹窗遮罩误拦截、TOML 注释丢失、账号组拖拽错位等界面与兼容问题。
- 更新：接入全链路启动与面板核心接口冒烟测试作为发版门禁，同步六语界面文案、六份安装文档、多语言 README、内置模型元数据及桌面端与手机端构建产物。
- 移除：下线旧版独立移动端目录、代理订阅及内置代理内核；暂不提供电脑端 Codex 对话与官方终端共享，保留普通模型对话及其他 Codex 接入能力。
- 版本：3.4.2 → 3.5.0
